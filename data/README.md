# Dataset Files

Run the MATLAB programs in `simulation/` or place identically named generated
files here. The canonical names are declared in `configs/final_protocol.json`.
Large MAT files are intentionally excluded from version control.
All MATLAB source code lives in `simulation/`; this directory is output-only.

The external ID, OOD, close-source, and drift sets are evaluation-only. Their
labels must not be used to train, select, or tune any model or threshold.
